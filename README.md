# 3D Dancing Model Landing Page

An interactive and visually engaging 3D landing page featuring a dancing character built with **HTML, CSS, JavaScript, GSAP, Bootstrap, and Google's `<model-viewer>`**. The project showcases a 3D GLB model with smooth loading animations, dynamic text transitions, and a modern gradient design.

## Features

- 🎭 Interactive 3D GLB model
- 🕺 Auto-playing dance animation
- 🎬 GSAP-powered entrance animations
- ⚡ Smooth loading screen
- 🎨 Animated gradient background
- 📱 Fully responsive layout
- 🚀 Lightweight and fast
- 🌐 Easy deployment on Netlify or Vercel

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/3d-dancing-model.git
```

### Navigate to the Project

```bash
cd 3d-dancing-model
```

### Open the Project

Simply open `index.html` in your browser or use a local development server.

Example using VS Code Live Server:

```
Right Click
→ Open with Live Server
```
